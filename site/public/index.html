Hold fast to every repository.

Holdfast keeps scheduled git mirrors of your GitHub repositories in your own Cloudflare account. If a repo is deleted, an account is suspended or GitHub is down, your code is still yours.

What it does

Built for the day GitHub isn't there.

Full git mirrors

Every branch, tag and commit, saved as a standard git bundle. Restore with one git clone.

Your schedule

Anything from every 5 minutes to every 365 days, per repository. Repos that haven't changed are skipped.

Whole accounts

Point it at a user or an organization. New repositories are picked up every day.

Private repos

Read-only GitHub tokens, one per owner, kept as encrypted secrets and sent only to github.com.

Locked by default

Cloudflare Access sign-in in front of every page. Without it, the portal refuses to open.

Deletions don't follow

A deleted repo or a force-push never removes your copies. An optional bucket lock makes them undeletable.

How it works

Three approvals, then it runs by itself.

01

Copy the prompt

Paste it into Claude Code, Codex, Cursor or any agent that can run commands on your machine.

02

The agent deploys

It asks which Cloudflare account and which GitHub accounts to back up, then creates the Worker, the D1 database and the R2 bucket.

03

You approve three things

The Cloudflare login, a read-only GitHub token from a pre-filled link, and the Access sign-in. Backups start within minutes.

Cost

Free, or $5 a month for big repos

On the Workers Free plan, Holdfast runs in free mode: repos up to 50 MB, one new copy every 5 minutes. Workers Paid removes those limits. Personal backups usually fit in R2's free 10 GB, and R2 charges nothing for downloads.

Limits

Know what it doesn't do

Git data only (no issues or pull requests yet), private repos on GitHub only, and very large repos may not finish in one run. Read all limitations →
